PortableForge portable copy
===========================

Run portableforge.exe from this folder. Keep portableforge-agent.exe
beside it. The helper works inside the test box during capture.

PortableForge stores settings and runs in the PortableForge and
PortableForge Sessions folders under your Windows user profile.

The bundled folder includes the Sandboxie-Plus 1.18.8 x64 portable payload at
bundled\Sandboxie-Plus. Sandboxie-Plus portable mode starts a Windows
service and driver with administrator approval. See SANDBOXIE-NOTICE.txt
in the bundled folder for startup, cleanup, and licensing.

This build is unsigned. The release page lists the genuine file hashes.
